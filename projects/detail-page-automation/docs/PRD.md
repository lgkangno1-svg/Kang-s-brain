# 상세페이지 자동 제작 서비스 PRD

**상태:** 서비스 개발 기준 문서  
**최종 갱신:** 2026-08-30 KST  
**프로젝트:** `projects/detail-page-automation`

## 1. 목표

과일·채소·정육·수산·가공식품 판매자가 상품 정보와 관련 사진/자료를 한 번 입력하면, 사람의 수동 제작 없이 24시간 언제든지 판매 전환형 상세페이지를 자동 생성하고 결과 이미지를 다운로드할 수 있는 서비스를 만든다.

고객은 내부 마스터 프롬프트나 제작 방식을 선택하지 않는다. 고객이 입력한 사실·업로드 자료·스타일 선택을 최우선으로 하고, 시스템이 내부적으로 가장 적합한 프롬프트 경로와 섹션 구성을 선택한다.

## 2. 상품 구성

### 체험형 — 9,900원
- 썸네일 1장
- 본문 8장
- 총 9장
- 이미지 품질: Medium
- 고객 업로드 자료 핵심 레퍼런스 최대 3개 우선 선별
- 실패 이미지 자동 재시도: 이미지당 최대 1회

### 기본형 — 14,900원
- 썸네일 2장
- 본문 10~12장
- 총 12~14장
- 본문 장수는 정보 밀도와 실제 확인 가능한 자료량을 보고 자동 결정
- 이미지 품질: High
- 고객 업로드 자료 핵심 레퍼런스 최대 6개 우선 선별
- 실패 이미지 자동 재시도: 이미지당 최대 2회

프리미엄형은 만들지 않는다.

## 3. 지원 카테고리
- 과일
- 채소
- 정육
- 수산
- 가공식품

스마트스토어형/쿠팡형 같은 상세페이지 목적 선택은 제공하지 않는다. 결과물은 범용 판매 전환형 상세페이지로 제작한다.

## 4. 최종 주문 폼

고객 선택 수를 가능한 한 줄인다.

### 필수
1. 체험형 / 기본형
2. 상품명
3. 카테고리
4. 상품 설명 자유입력
5. 메인 비주얼 스타일: 남자 모델 / 여자 모델 / 농가에서 찍은 느낌 / 제품 중심 / 프리미엄 스튜디오
6. 모델컷 수: 0 / 2 / 4 / 6
7. 전체 톤: 화이트 / 베이지 / 블랙 / 내추럴 그린 / 럭셔리 다크
8. 카피 분위기: 감성 / 전문 / 신뢰 / 판매 / 선물
9. 정보 밀도: 심플 / 표준 / 정보 많음
10. 강조 포인트 복수선택: 신선도 / 가격 / 원산지 / 맛 / 영양·건강정보 / 선물 / 대용량 / 가성비
11. 썸네일 성격: 강한 판매 / 감성 / 고급 / 정보형
12. AI 이미지 내 문구 오탈자 안내 동의

### 선택
- 상품 구성 / 규격
- 판매 가격
- 꼭 넣고 싶은 내용
- 빼고 싶은 내용
- 상품 관련 사진/자료 업로드

## 5. 빈 정보 처리

고객이 `상품 구성/규격`을 입력하지 않으면 상세페이지에 규격 관련 주장이나 `[정보 확인 필요]` 같은 내부 표시를 넣지 않는다.

고객이 `판매 가격`을 입력하지 않으면 가격을 표시하지 않고 유사상품 가격을 검색하거나 추측하지 않는다. 가격을 전제로 하는 가성비 주장도 만들지 않는다.

같은 원칙을 원산지, 인증, 시험성적, 당도/수치, 실제 후기/평점/판매량, 배송방법, 건강 효능 등에 적용한다. 근거가 없는 설득 축은 다른 확인 가능한 구매 이유로 교체한다.

## 6. 업로드 UX

고객에게 제품사진/패키지/성적서/후기 등 별도의 업로드 선택창을 만들지 않는다.

표시 문구:

> 가지고 있는 상품 사진이나 자료를 자유롭게 올려주세요. AI가 내용을 분석해 필요한 곳에 자동으로 활용합니다.

한 업로드 영역에서 여러 파일을 받고 내부에서 자동 분류한다.

내부 후보 분류: 상품 전체샷 / 근접샷 / 단면·질감 / 패키지 / 배송·개봉 / 농가·산지 / 성적서·인증·증빙 / 후기 캡처 / 디자인 레퍼런스 / 기타.

업로드한 실제 상품 자료는 Product Ground Truth로 취급한다. 배경·조명·구도·소품은 개선할 수 있으나 상품의 실제 색상, 형태, 크기 비율, 포장, 라벨, 품종 특징 등 정체성을 임의로 바꾸지 않는다.

모든 업로드를 모든 이미지 생성 호출에 넣지 않는다. 품질·상품 식별력·용도·중복도를 평가해 체험형 최대 3개, 기본형 최대 6개의 핵심 레퍼런스를 우선 선별하고 각 이미지에 필요한 레퍼런스만 전달한다.

## 7. 고객 우선순위

충돌 시 아래 순서를 강제한다.

1. 고객이 업로드한 실제 상품/객관 자료
2. 고객이 직접 입력한 확인된 사실
3. 고객이 선택한 스타일/옵션
4. 구매한 상품 플랜 계약
5. 안전하게 추론 가능한 내용
6. 마스터 프롬프트 기본값
7. 내부 랜덤 스타일

예: 마스터가 화이트여도 고객이 블랙을 선택하면 블랙. 마스터가 모델 3컷 이상이어도 고객이 0컷을 선택하면 모델 0컷. 생성 모델이 다른 포장을 상상해도 실제 업로드 포장이 우선한다.

## 8. 내부 마스터 프롬프트 경로

고객에게 제작 방식 선택창을 노출하지 않는다. 고객이 보는 결과는 항상 판매 전환형이다.

### Route A — 직접 판매전환 마스터
제품 정보가 단순하거나 차별 근거가 적으면 `유튜브 그대로 상페 (1).txt` 기반으로 바로 제작한다. 원본 안의 사용자 확인 단계는 무인 서비스에서 자동 승인하고 작업을 멈추지 않는다.

### Route B — TED Q1~Q10 자동완성 → 개선 마스터
차별 근거·브랜드 원칙·성적서·공정·스토리 등 활용 가능한 근거가 충분하면 `TED 상페- 고객님 정보요청.txt`의 Q1~Q10을 AI가 먼저 자동 작성한 뒤 `마스터프롬프트 개선버전.txt`에 주입한다.

Q1~Q10 작성 시 `CONFIRMED / SAFE INFERENCE / UNVERIFIED`를 구분하고 가격·원산지·규격·인증·검사결과·효능 같은 하드 팩트를 임의 생성하지 않는다. Route는 고객에게 노출하지 않는다.

## 9. 결과 다양화

고객 선택값을 확정한 뒤 Hero 구도, 카메라/크롭, 설득 섹션 순서, 정보 카드 표현, 타이포 구성, CTA, 배경 질감, 인포그래픽 밀도, 라이프스타일 장면 등을 주문별 deterministic seed로 변화시킬 수 있다. 랜덤화는 고객 선택이나 Product Ground Truth보다 우선할 수 없다.

## 10. 이미지 생성 경로

두 실행 모드를 명확히 분리한다.

- **내부 개발/샘플 제작 모드:** ChatGPT 로그인 기반 Codex의 이미지 생성 기능을 사용할 수 있다.
- **24시간 고객 서비스 모드:** 결제·큐·재시도·동시성·비용 추적이 가능한 서버측 이미지 API worker를 사용한다.

서비스 모드의 기본 이미지 모델 목표는 `gpt-image-2`다.
- 체험형 → Medium
- 기본형 → High

고객 서비스 백엔드를 브라우저/소비자 Codex 세션 자동조작으로 구현하지 않는다.

## 11. 오타/글자 깨짐 필수 고지

결제/주문 확정 전에 반드시 눈에 보이게 안내하고 명시적 동의를 받는다.

> **AI 이미지 내 문구 오탈자 안내**  
> AI 이미지 생성 특성상 이미지 안의 한글·숫자·문구에 오탈자, 글자 깨짐 또는 왜곡이 발생할 수 있습니다. 이미지 내부에 생성된 글자는 일반 문서의 텍스트처럼 직접 수정하기 어려워 일부 결과는 이미지 재생성이 필요할 수 있으며, 재생성을 하더라도 완벽한 오탈자 교정을 보장할 수 없습니다.

- 동의하지 않으면 주문 확정 불가
- 동의한 고지 버전 저장
- 자동 QA로 명백한 글자 실패를 탐지해 플랜 재시도 한도 내 재생성
- 완벽한 한글 교정을 보장한다고 광고하지 않음

## 12. 자동 생성 파이프라인
1. 주문 입력/업로드 수신
2. 오타 고지 동의와 플랜 계약 검증
3. 빈 선택값 정규화/제외
4. 업로드 비공개 저장 및 내부 분류
5. 중복 제거 및 핵심 레퍼런스 선별
6. 확인된 사실/증거 추출
7. 내부 마스터 Route 자동 결정
8. 고객 우선순위가 반영된 전략/카피/이미지 작업 정의 생성
9. 이미지 비용을 쓰기 전에 사실/중복/금지문구 검사
10. 플랜 품질/장수로 이미지 생성
11. 이미지별 자동 QA
12. 실패 이미지만 재시도
13. 본문 이미지 연결본과 개별 이미지 생성
14. ZIP 패키징
15. 완료 상태 및 다운로드 제공

## 13. 24시간 운영 아키텍처 목표
- Web: 주문/업로드/결제/상태/다운로드
- DB: 주문, 작업, 단계, 비용, 동의 버전, 출력 manifest
- Private Storage: 고객 업로드/생성 이미지/ZIP
- Worker: MiniPC의 장기 실행 Node/Python worker 또는 동등한 서버 런타임
- n8n: stale job 감지/운영 알림
- Image provider: GPT-Image-2 adapter
- Text planner: 벤치마크 후 교체 가능한 저비용 provider adapter

결제 provider는 현재 PRD에서 확정하지 않는다. 결제가 붙으면 검증된 서버측 결제 이벤트가 없는 주문은 이미지 생성 큐에 들어갈 수 없다.

## 14. 비용 통제
- 플랜별 이미지 장수 하드캡
- 이미지별 재시도 하드캡
- 모든 업로드를 모든 요청에 붙이지 않음
- 이미지 생성 전에 텍스트/팩트 QA 완료
- 실패 이미지만 재생성
- 요청/이미지별 사용량 및 원가 저장
- 공개 출시 전 일/월 비용 한도와 비정상 사용 차단 추가

## 15. MVP 완료 조건
1. 최종 짧은 주문폼 제출 가능
2. 빈 규격/가격이 결과에서 실제로 제외됨
3. 오타 고지 동의를 우회할 수 없음
4. 업로드를 하나의 영역에서 받아 자동 분류/선별함
5. 고객이 모르는 상태에서 내부 Route가 자동 결정됨
6. 고객 선택이 마스터 기본값보다 우선함
7. 체험형: 1+8, Medium
8. 기본형: 2+10~12, High
9. 성공한 이미지는 유지하고 실패한 이미지만 재시도
10. 미확인 사실을 사실처럼 쓰지 않음
11. 개별 이미지 + 연결 상세 + ZIP 다운로드
12. 주문별 provider 사용량/비용 추적 가능
