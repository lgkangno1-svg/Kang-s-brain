# Hanbok rental shortlist quality gate — 2026-09-12

## Product rule

The customer-facing Gyeongbokgung rental finder must remain a **focused shortlist of 10 shops or fewer**. Proximity or low price alone is not enough for inclusion.

A shop should have at least one strong, current signal:

1. unusually high public review volume / sustained rating evidence;
2. a clearly large inventory or operation;
3. meaningful international booking volume / multilingual traveler support;
4. established recognition among overseas visitors.

Prefer primary shop sources for hours, address, language support and return rules. Use international booking/review platforms only as supporting evidence for popularity and traveler adoption. Do not imply partnership, endorsement, guaranteed stock, guaranteed language support, or live availability.

## Exclusion behavior

Do not add a shop merely because it appears in an official directory or is physically close to the palace. If popularity/scale/international-recognition evidence is weak, keep it out of the recommendation shortlist until stronger evidence exists.

Review counts are snapshots and can change quickly, so the production UI should avoid hard-coding live counts unless the value has a checked-at timestamp and a refresh policy. The runtime support note should explain the durable reason a shop was selected.
